# Teaching briefs

Reference notes (not app code, not session data) that record the reasoning behind specific additions to `data/sessions/*.js`. Written elsewhere, dropped in here by Will, then applied chapter-by-chapter into the session files by Claude.

- `MILLENNIAL-GUIDE-BRIEF.md` — how to teach the millennial-kingdom question generally (verses first, four views, leave it in the room). Not yet applied anywhere specific — it's the pattern to follow when Revelation gets its deeper rewrite and when Ezekiel/Isaiah/Daniel's kingdom texts are drafted.
- `PAULINE-CHRONOLOGY.md` — how the Pauline letters are dated (Gallio/Delphi as the one hard peg) and the file-grouping plan for the epistles. Applied.
- `PAULINE-AUTHORSHIP.md` — the three chairs on who wrote which of the thirteen "Pauline" letters. Applied.
- `PAULINE-COMMENTARY.md` — teacher-only deep background (the Gallio inscription in full, why the Seneca-Paul letters are 4th-century fiction) with a table of exactly where each piece drops into which chapter. Applied.
- `HEBREWS-MELCHIZEDEK.md` — the entire Melchizedek dossier (Genesis 14, Psalm 110, Hebrews 5-7) and the Second Temple/rabbinic background behind it. Applied.

Each file's own "Status" note at the bottom says what's been added and where. If a brief's content is revised later, the same chapters should be re-checked against the updated brief.
